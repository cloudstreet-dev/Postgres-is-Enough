# Postgres Is Enough

A love letter to PostgreSQL — exploring how far you can push it as a relational DB, document store, job queue, key-value store, vector database, time-series store, and beyond. With the right extensions and knowledge, Postgres is enough.

Read it at: **https://cloudstreet-dev.github.io/Postgres-is-Enough/**
